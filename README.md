# Тише — читать и слушать

Веб-читалка: https://alekseyrud24-ui.github.io/tishe/

Собственный голосовой мост: https://tishe-voice.aleksey-rud24.workers.dev

## Microsoft на телефоне и компьютере

В группе **Microsoft · облачный мост · любой браузер** доступны
`ru-RU-DmitryNeural` и `ru-RU-SvetlanaNeural`. Для нового браузера выбран Дмитрий.
Сохранённый текст, позиция, настройки и выбранный голос остаются в том же
локальном хранилище, что и в предыдущей версии.

- Голоса не подменяются ни системным синтезом, ни Google при сбое Microsoft.
- Worker сначала использует Microsoft Edge endpoint, затем Bing Read Aloud.
  Оба маршрута синтезируют тот же голос с той же скоростью и высотой.
  Это резерв транспорта, не независимый от Microsoft поставщик голосов.
- Worker возвращает MP3 только после `turn.end`, получения аудио и метаданных.
  Незавершённая запись не попадает в кэш.
- Запас — от 1 до 20 **целых предложений**. На новом устройстве установлен 20.
  Следующий блок начинает загружаться сразу после завершения текущего.
  Загрузка последовательная; пользовательские паузы остаются отдельной настройкой.
- При временной ошибке — первоначальный запрос и максимум 20 повторов с
  одинаковой задержкой 2 секунды. `Retry-After` может увеличить ожидание;
  ожидание отсутствующей сети не расходует попытки. Позиция не пропускается.
- Пауза не возобновляет чтение сама; остановка, смена голоса и переход по тексту
  отменяют старые запросы. Если браузер требует прямого нажатия, готовая запись
  сохраняется и на экране появляется просьба нажать ▶ ещё раз.

## Кэш и данные

Текст для озвучивания передаётся собственному Worker на Cloudflare и Microsoft.
Рукопись и позиция остаются в `localStorage` браузера. Аудио хранится:

1. В ограниченном оперативном буфере читалки.
2. В IndexedDB браузера: до 48 МиБ, 160 записей, срок повторного использования
   7 дней. Ключ зависит от текста, голоса, скорости, высоты и версии клиента.
3. В Cloudflare Cache API: до суток, с хешированным ключом; текст не включён
   в URL. Ошибки не кэшируются. Доступность edge-кэша не гарантируется.

Запись логов Worker выключена. API ограничивает голоса, параметры, длину текста,
размер тела и аудио; CORS разрешает сайт читалки и локальные адреса проверки.
Внутрипроцессный лимит 180 запросов/минуту на IP — дополнительный best-effort
барьер, не полноценная защита публичного API от злоупотреблений. Секрет, встроенный
в открытую страницу, не защищал бы API, поэтому фиктивного секретного ключа нет.

Worker опубликован на существующем Workers Free, без KV/R2/D1 и платных сервисов.
Доступность Microsoft и доступ к домену workers.dev у конкретного оператора
не гарантируются. При исчерпании бесплатного лимита сервис может остановиться;
автоматического перехода на платный тариф этот проект не делает.

## Исходники и публикация

- `app.js` — плеер, позиции, блоки и повторные подключения.
- `cloud-microsoft.js` — HTTPS-клиент и локальный аудиокэш.
- `microsoft-direct.js` — прежний прямой транспорт и общая формула протокола.
- `source.html`, `tishe.css`, `build.py` — однофайловая сборка.
- `cloudflare/worker.js` — облачный мост.
- `cloudflare/protocol.js` — генерируется сборщиком из существующего протокола.
- `cloudflare/wrangler.jsonc`, `package-lock.json` — воспроизводимое размещение.

Сборка страницы: `python build.py --output index.html`.
Для зависимостей Worker: `npm ci` в `cloudflare/`; публикация: `npm run deploy`.
Wrangler должен быть авторизован штатным OAuth. На Windows использовано
зашифрованное хранилище Wrangler с ключом в Windows Credential Manager;
пароли и OAuth-токены в репозиторий не включены. Подробности учётных данных
не нужно записывать в исходники, README или историю Git.

Проверки (запускаются отдельно от публикации):

- `npm test` в `cloudflare/` — валидация, сохранение голоса в fallback,
  отмена, уважение HTTP 429, CORS и формат WebSocket-пакетов.
- `node cloudflare/test/retry-prefetch.cjs index.html all` — 20 повторов,
  постоянная задержка, `Retry-After`, пауза, 20+20 и восстановление неполного блока.
- `python cloudflare/test/relay_probe.py` — реальные записи обоих голосов
  на обоих маршрутах, полное декодирование FFmpeg и повтор через edge-кэш.
- `node test/reader-e2e.mjs https://alekseyrud24-ui.github.io/tishe/` из
  `cloudflare/` — Chrome в отдельном временном профиле, реальные предпрослушивания,
  40 предложений, загрузка и воспроизведение на границе блоков, IndexedDB,
  пауза/продолжение, восстановление позиции и повтор после искусственного HTTP 503.

Для последней проверки требуется установленный Chrome. Существующие сетевые
proxy-переменные применяются только к изолированному тестовому браузеру;
настройки пользовательских браузеров не меняются. Размер 390×844 в проверке —
эмуляция окна, а не подтверждение работы на физическом iPhone или Android.

## Ориентиры реализации

- https://github.com/DIYgod/cloudflare-edge-tts — архитектура лёгкого Worker
  и независимая сверка результата формулы Sec-MS-GEC.
- https://github.com/readest/readest — архитектура предзагрузки и кэширования
  в читалке. Реализация плеера сохранена из «Тише», а не заменена Readest.

Чужие демонстрационные Worker, Hugging Face Spaces, платные API и сторонние
прокси для текста читалка не использует. Фоновое чтение с заблокированным экраном
зависит от ОС/браузера и не подтверждается настольными автотестами.
